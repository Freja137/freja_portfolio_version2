Hvordan jeg arbejder

Jeg arbejder i krydsfeltet mellem UX-design og frontendudvikling – fra research og prototyping til responsiv, tilgængelig kode. Jeg er nysgerrig på, hvordan tingene hænger sammen, og følger gerne en idé hele vejen fra skitse til færdig løsning.

Jeg arbejder struktureret og lægger vægt på overblik, kvalitet og gennemarbejdede detaljer. Jeg kan lide at fordybe mig og blive udfordret, især når jeg kan omsætte det, jeg lærer, til noget, der virker i praksis.

Udforsk mine projekter

</> Det arbejder jeg i

Design

I Figma arbejder jeg fra wireframes og user flows til mockups og klikbare prototyper, som kan testes med brugere. Genbrugelige komponenter holder designet konsistent på tværs af sider. Affinity bruger jeg til billedbehandling og grafiske elementer.

Kode

Jeg skriver semantisk HTML og responsiv CSS med en mobile first-tilgang og bruger JavaScript til interaktion og data fra REST API'er. Med Vue bygger jeg komponentbaserede løsninger med reaktiv data, og med PHP henter og viser jeg indhold dynamisk.

WordPress

Jeg bruger WordPress både som klassisk og som headless CMS. Jeg udvikler skræddersyede temaer med PHP-skabeloner, Custom Post Types og Advanced Custom Fields, så indholdet får en fast struktur, som kunden selv kan redigere.

Arbejdsgang

Jeg koder i VS Code og versionsstyrer med Git og GitHub, hvor vi i gruppeprojekter arbejder med branches og pull requests. Vite bruger jeg til at sætte Vue-projekter op og bygge dem til produktion, og med GitHub Actions har jeg automatiseret deployment.

</> Det bidrager jeg med

Jeg omsætter design til responsiv og tilgængelig frontend med fokus på semantisk struktur, tastaturnavigation og tydelige fokustilstande.

Gennem API-integration og komponentbaseret udvikling bygger jeg dynamiske løsninger, hvor indhold, funktionalitet og brugeroplevelse hænger sammen. Undervejs tester jeg med Lighthouse for at forbedre performance, tilgængelighed og SEO.

Før jeg designer, skaber jeg overblik over indholdet. Med informationsdesign, indholdsmodeller og content sitemaps fastlægger jeg, hvilke oplysninger hver side skal rumme, og hvordan siderne hænger sammen.

Derefter udforsker jeg forskellige løsninger gennem skitser og metoder som fx Crazy 8, før de bliver til wireframes og mockups til både mobil og desktop. Genbrugelige komponenter, med inspiration fra Atomic Design, giver sammenhæng på tværs af siderne.

Gennem iterative processer tester jeg klikbare prototyper med brugere, fx med 5-second test og think-aloud, og bruger resultaterne til at forfine designet, så det bliver mere intuitivt og velfungerende.

Jeg starter med desk research og segmentering ud fra objektive og subjektive kriterier for at forstå målgruppen og dens forskellige behov og formål.

Med semistrukturerede interviews går jeg i dybden med brugernes egne erfaringer. Svarene transskriberes og analyseres tematisk og bruges i den efterfølgende designprocess.

Gennem affinity diagram og metoder som card sorting undersøger jeg, hvordan indhold hænger sammen samt, hvordan brugerne selv organiserer indholdet, så navigation og struktur følger deres forståelse frem for min egen.

</> Som kollega

Samarbejde

Jeg er rolig og lyttende og lægger vægt på dialog og gensidig forståelse. Jeg bidrager gerne med struktur i fælles processer, fra fordeling af opgaver til gennemgang af hinandens kode via pull requests.

Proces

Jeg holder styr på mine opgaver og deler løbende, hvor langt jeg er, så resten af teamet ved, hvad de kan regne med. Jeg tager imod feedback og bruger den til at gøre løsningen bedre.
